What is worth writing about

  • A file that will not open, or that opens and then stops halfway. Say which container and codec it was — ffprobe output if you have it.
  • An encode that came out visibly worse than it should have, or well under the target size when it did not need to be.
  • A limit on this site that no longer matches what the platform actually allows.

What to expect

Best effort, usually within a few days. This is a one-person project, not a support desk, and there is no account to look into — your files never reached this site, so there is nothing on this end to inspect. Send the file only if you want to, and only if you are comfortable doing so.

Privacy of your message

Your message and address are used to answer you and for nothing else. There is no newsletter. See Privacy for what the site itself does, which is very little.
